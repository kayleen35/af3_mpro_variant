# Scoring MVP

The score is a heuristic research-priority indicator from 0 to 100.

Inputs:

- docking score
- binding affinity nM
- molecular weight
- logP
- ADMET risk score
- novelty score
- data quality score

Outputs:

- research_priority_score
- target_fit_score
- drug_likeness_score
- data_confidence_score
- risk_penalty
- rationale

This scoring function is not a clinical, therapeutic, safety, or synthesis feasibility assessment.
