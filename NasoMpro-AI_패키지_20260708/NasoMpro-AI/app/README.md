# SARS-CoV-2 Mpro 비강 항바이러스 후보 평가 플랫폼

제4회 JUMP AI 신약개발 경진대회용 no-code 실행형 Streamlit 제품입니다. SARS-CoV-2 Mpro(3CL protease) 저해제 후보 ligand의 구조 유사도, RDKit 물성, 비강 전달 적합성, QED, 종합 점수를 계산합니다.

## 실행 방법

1. `app` 폴더 안의 `실행.bat`을 더블클릭합니다.
2. 첫 실행에서는 `.venv` 가상환경을 만들고 `streamlit`, `rdkit`, `pandas` 등을 설치하므로 시간이 걸릴 수 있습니다.
3. 설치 후 브라우저에서 앱이 열립니다.

## 주요 기능

- `후보 평가`: SMILES 1개를 입력하고 RDKit 구조 이미지, 물성 테이블, 4축 점수, 산식을 확인합니다.
- `랭킹`: 여러 SMILES를 한 줄씩 입력해 후보를 종합 점수 기준으로 정렬하고 CSV로 저장합니다.
- `에이전트 파이프라인`: 계산 결과를 기반으로 가설생성, 구조/결합, 분자최적화, 비강제형, 규제 단계 판단을 생성합니다. API 키가 없으면 규칙 기반으로 동작합니다.

## 기준 물질

- Nirmatrelvir
- Ensitrelvir
- GC376

각 기준 물질의 SMILES는 공개 화학 데이터베이스의 구조 표기를 사용하며, 계산은 RDKit로 수행됩니다.
